### Link Disavowal Protocol

Once per quarter, audit the backlink profile in Ahrefs or Google Search Console. If you identify:
- Links from link farms, irrelevant directories, or spammy sites
- Anchor text over-optimisation (more than 20% of links using exact-match "hospital marketing agency Bengaluru")

Create a disavowal file and submit via Google Search Console → "Links" → "Disavow links". Do not disavow more than 5% of your link profile without expert review.
